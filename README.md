## Workflow
1. Scene plan based on voice timing
2. Chunk rendering (each scene rendered separately, then joined)
3. Soft BGM under voice + subtle SFX
4. 5-point preview checklist before final render: timing, positioning, subtitles, sound balance, scene variety
